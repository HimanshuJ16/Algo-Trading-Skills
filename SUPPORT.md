# Support Guidelines — Algo-Trading-Skills

Thank you for using **Algo-Trading-Skills**! Here is how to get help, report issues, or contribute.

## 💬 Where to Ask Questions vs. File Issues

| Need | Best Place | Link |
|---|---|---|
| **Usage Questions & Design Advice** | GitHub Discussions | [Ask a question](https://github.com/HimanshuJ16/Algo-Trading-Skills/discussions) |
| **Bug Reports** (Broken scripts, inaccurate workflows) | GitHub Issues | [Report a bug](https://github.com/HimanshuJ16/Algo-Trading-Skills/issues/new?template=bug_report.md) |
| **New Skill / Platform Proposals** | GitHub Issues | [Propose a feature](https://github.com/HimanshuJ16/Algo-Trading-Skills/issues/new?template=feature_request.md) |
| **Security Concerns** | Security Policy | [Report security issue](SECURITY.md) |
| **Community Conduct** | Code of Conduct | [View guidelines](CODE_OF_CONDUCT.md) |

## 🐞 Reporting Bugs

When submitting a bug report:
1. Identify the specific skill directory (e.g. `skills/order-placement-idempotency/SKILL.md`).
2. Provide the exact steps or code snippet that triggered the issue.
3. State your environment (Python version, operating system, broker/exchange API version).

## 🚀 Contributing

We welcome community contributions! Please refer to [CONTRIBUTING.md](CONTRIBUTING.md) for details on formatting skills according to the `agentskills.io` standard and running `python tools/validate_skills.py`.
