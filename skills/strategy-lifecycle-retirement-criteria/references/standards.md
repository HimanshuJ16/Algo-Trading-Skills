# Standards for Strategy Lifecycle Retirement Criteria

| Metric | Minimum Healthy Threshold | Description |
|---|---|---|
| Information Ratio (IR) | $\ge 0.50$ | Minimum risk-adjusted excess return efficiency. |
| Max Drawdown Multiplier | $\le 1.50 \times \text{Backtest DD}$ | Prevents unpredicted tail drawdowns. |
| IC t-statistic | $\ge 1.96$ | Enforces 95% statistical confidence in alpha signal. |
| Max Performance Drift | $\ge -40.0\%$ | Caps live vs backtest performance divergence. |
