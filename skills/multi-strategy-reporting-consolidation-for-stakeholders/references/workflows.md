# Workflows for Multi-Strategy Reporting Consolidation

1. **Capital & PnL Aggregation**:
   - Aggregate sub-strategy capital allocations, realized PnL, and unrealized PnL.
2. **Joint Return & Volatility Synthesis**:
   - Synthesize portfolio daily return series and compute portfolio annualized volatility.
3. **Sharpe & Diversification Audit**:
   - Compute portfolio Sharpe ratio and diversification benefit ratio ($\frac{\sum w_k \sigma_k}{\sigma_p}$).
4. **Audit Report Generation**:
   - Output structured executive reporting report.
