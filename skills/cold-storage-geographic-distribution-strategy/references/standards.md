# Standards for Cold Storage Distribution

| Metric | Engineering Standard |
|---|---|
| Threshold Safety | No single legal jurisdiction or single provider MUST hold $\ge M$ shards in an $M$-of-$N$ scheme. |
| Physical Security | All shard storage facilities MUST possess ISO 27001 or SOC 2 Type II compliance certificates. |
| Redundancy Reserve | The threshold gap $(N - M)$ MUST be $\ge 2$ to allow for shard loss without total asset lock. |
