# Standards for Co-Location Evaluation

| Metric | Engineering Standard |
|---|---|
| Fiber Speed Metric | Standard silica fiber propagation MUST be calculated at $5.00\ \mu\text{s/km}$ ($200\text{ km/ms}$). |
| Microwave Speed Metric | Free-space RF propagation MUST be calculated at $3.33\ \mu\text{s/km}$ ($300\text{ km/ms}$). |
| Patch Cord Equivalence | All cross-connect cables within the same cage MUST be ordered with matched lengths to avoid intra-rack skew. |
