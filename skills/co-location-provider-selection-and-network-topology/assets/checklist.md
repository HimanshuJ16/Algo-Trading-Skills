# Pre-Flight Checklist

- [ ] Are physical fiber distances accurately measured (cable route vs straight line)?
- [ ] Is propagation delay computed using $5.0\ \mu\text{s/km}$ for fiber and $3.33\ \mu\text{s/km}$ for microwave?
- [ ] Are switch hop latency and cross-connect patch delays included in the latency budget?
- [ ] Does the TCO model account for power density (kW/rack) and cross-connect MRC?
