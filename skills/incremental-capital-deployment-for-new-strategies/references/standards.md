# Standards for Incremental Capital Deployment

| Metric | Engineering Standard |
|---|---|
| Tier Allocation Percentages | Tier 0 = 0%, Tier 1 = 10%, Tier 2 = 50%, Tier 3 = 100%. |
| Tier 1 Promotion Gate | Must operate $\ge 30$ live days with Sharpe $\ge 1.0$ and Max DD $\le 5.0\%$. |
| Emergency Kill Switch Limit | Max Drawdown $\ge 12.0\%$ MUST trigger immediate demotion to Tier 0 ($0\%$ allocation). |
