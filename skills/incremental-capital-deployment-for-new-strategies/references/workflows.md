# Workflows for Incremental Capital Deployment

1. **Drawdown & Health Audit**:
   - Audit realized drawdown against emergency limit (12%).
2. **Promotion Gate Evaluation**:
   - Audit days in tier, realized Sharpe ratio, and execution slippage.
3. **Capital Allocation Calculation**:
   - Assign tier allocation percentage (0%, 10%, 50%, 100%) and calculate USD allocation.
4. **Audit Report Generation**:
   - Output structured deployment report.
