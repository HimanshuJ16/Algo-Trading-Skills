# Pre-Flight Checklist

- [ ] Is TIDM ticker symbol 2-4 uppercase characters (`SHEL`, `AZN`)?
- [ ] Is order price quoted in GBX (Pence)?
- [ ] Is dynamic GBX tick size verified against MiFID II price tier?
- [ ] Is equivalent GBP notional calculated correctly ($V_{\text{GBP}} = \frac{P_{\text{GBX}} \times Q}{100}$)?
