# Standards for LSE Millennium Exchange

| Metric | Engineering Standard |
|---|---|
| Price Currency | LSE equities MUST be quoted and submitted in GBX (Pence), NOT GBP. |
| Ticker Standard | Tradable Instrument Display Mnemonic (TIDM) MUST be 2-4 uppercase characters. |
| Tick Size Regime | Order prices MUST conform to 7-tier MiFID II RTS 28 GBX tick schedules. |
