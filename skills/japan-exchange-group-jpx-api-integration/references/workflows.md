# Workflows for JPX TSE Integration

1. **Local Stock Code Audit**:
   - Verify 4-digit numeric Japanese ticker code (`7203`).
2. **JPY Price Tick Tier Calculation**:
   - Compute dynamic TSE tick size based on price level.
3. **Board Lot Sizing Audit**:
   - Verify order quantity is a multiple of 100 shares.
4. **Audit Report Generation**:
   - Output structured JPX order report.
