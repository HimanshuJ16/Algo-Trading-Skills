# Standards for JPX Integration

| Metric | Engineering Standard |
|---|---|
| Stock Code Format | TSE equity codes MUST be 4 digits (e.g. `7203`). |
| Board Lot Sizing | Orders MUST be submitted in multiples of 100 shares ($1\text{ Unit}$). |
| Tick Size Rules | Order prices MUST conform to TSE price-tier tick schedules. |
