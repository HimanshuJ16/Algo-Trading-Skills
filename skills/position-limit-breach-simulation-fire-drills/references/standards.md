# Standards for Position Limit Breach Simulation Fire Drills

| Metric | Engineering Standard |
|---|---|
| Risk Evaluation SLA | Pre-trade risk gateway evaluation MUST complete in $\le 5.0\text{ ms}$. |
| Intraday Limit Enforcement | Compliance MUST be enforced continuously on an intraday tick basis. |
| Environment Isolation | Fire drills MUST run in sandbox/staging, NEVER in live trading. |
