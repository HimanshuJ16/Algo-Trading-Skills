# Workflows for Position Limit Breach Simulation Fire Drills

1. **Fire Drill Scenario Injection**:
   - Inject simulated limit breach scenarios (Exchange Limit, Broker Limit, Rogue Algo).
2. **Pre-Trade Risk Gateway Audit**:
   - Verify risk gateway blocks order within sub-5ms SLA.
3. **Kill Switch & Notification Audit**:
   - Confirm automated kill switch trips and compliance alerts are logged.
4. **Audit Report Generation**:
   - Output structured fire drill report.
