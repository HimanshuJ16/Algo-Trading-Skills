# Standards for Opening Auction Imbalance-Based Execution

| Metric | Engineering Standard |
|---|---|
| Imbalance Ratio Threshold | Minimum $\ge 0.20$ ($20\%$) imbalance ratio to trigger contra-side order. |
| Cutoff Window Lockout | Orders MUST be submitted before exchange lockout window (120s to open). |
| Order Type | Market-On-Open (MOO) or Limit-On-Open (LOO) MUST be used. |
