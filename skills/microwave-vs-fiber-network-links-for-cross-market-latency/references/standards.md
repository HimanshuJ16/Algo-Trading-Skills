# Standards for Network Link Arbitration

| Metric | Engineering Standard |
|---|---|
| Speed of Light in Air | $c_{\text{air}} = 299,700\text{ km/s}$ MUST be used for Microwave line-of-sight propagation. |
| Speed of Light in Fiber | $c_{\text{fiber}} = 203,945\text{ km/s}$ MUST be used for Fiber silica glass propagation. |
| Rain Fade Failover | Automatic failover to Fiber MUST trigger when packet loss $> 1.0\%$ or heavy rain occurs. |
