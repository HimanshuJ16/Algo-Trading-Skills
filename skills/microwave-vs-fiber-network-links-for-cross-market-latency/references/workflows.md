# Workflows for Network Link Arbitration

1. **Light Propagation Physics Audit**:
   - Calculate one-way and round-trip propagation latency for Microwave and Fiber links.
2. **Latency Advantage Computation**:
   - Compute millisecond savings and percentage speed advantage of wireless links.
3. **Rain Fade Telemetry & Failover Audit**:
   - Audit weather state and packet loss; trigger failover to Fiber if needed.
4. **Audit Report Generation**:
   - Output structured network link report.
