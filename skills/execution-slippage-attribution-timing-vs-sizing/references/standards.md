# Standards for Execution Slippage Attribution

| Metric | Engineering Standard |
|---|---|
| Decomposition Identity | $\text{IS}_{\text{total}} \equiv \text{IS}_{\text{timing}} + \text{IS}_{\text{sizing}}$ MUST hold exactly. |
| Side Multiplier Standard | Buy orders (+1) and Sell orders (-1) MUST apply correct side sign multiplier. |
| Basis Point Precision | All slippage components MUST be reported in basis points (bps) with 2 decimal places. |
