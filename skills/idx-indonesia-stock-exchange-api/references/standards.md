# Standards for IDX Integration

| Metric | Engineering Standard |
|---|---|
| Ticker Format | IDX equity tickers MUST be 4 uppercase letters (e.g. `BBCA`). |
| Tick Size Rules | Order prices MUST conform to IDX Fraksi Harga. |
| Board Lot Sizing | Regular and Cash market orders MUST be in multiples of 1 Lot ($100$ shares). |
