# Promotion Workflow: Testnet to Mainnet

1. **Paper Trading (Testnet)**
   - Confirm the strategy functions correctly on the Binance Futures Testnet.
   - Validate API connectivity and basic order placement logic.

2. **Pre-Flight Validation**
   - Check HTTPS configurations.
   - Verify Mainnet API credentials securely.
   - Assert risk limits (max leverage, max portfolio heat).

3. **Small-Scale Mainnet (Pilot)**
   - Start with minimal capital.
   - Verify slippage and real-world execution latencies align with assumptions.

4. **Scaling**
   - Gradually increase capital allocation after consistent, verifiable performance.
