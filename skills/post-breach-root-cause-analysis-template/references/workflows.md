# Workflows for Post-Breach Root Cause Analysis Template

1. **Incident Data Ingestion**:
   - Ingest incident metadata, timeline events, 5-Whys analysis, and CAPA action items.
2. **Quality Audit & Validation**:
   - Verify 5-Whys depth (at least 3 levels) and non-empty action items.
3. **Report Generation**:
   - Generate formatted Markdown RCA report and JSON audit payload.
4. **Audit Output**:
   - Output structured RCA report.
