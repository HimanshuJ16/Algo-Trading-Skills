# Workflows for Japan FSA HST Compliance

1. **FIEA HST Classification**:
   - Audit automation, co-location, and low-latency access to classify HST status.
2. **FSA Registration Verification**:
   - Audit active FSA High-Speed Trader registration number.
3. **Pre-Trade Risk & Kill Switch Audit**:
   - Audit pre-trade value limits, emergency kill switch controls, and compliance manager appointment.
4. **Audit Report Generation**:
   - Output structured Japan FSA HST compliance report.
