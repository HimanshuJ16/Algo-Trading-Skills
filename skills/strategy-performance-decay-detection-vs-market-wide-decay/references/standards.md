# Standards for Strategy Performance Decay Detection vs Market-Wide Decay

| Parameter | Standard Requirement |
|---|---|
| Idiosyncratic Z-Score Threshold | $Z \le -1.96 \implies$ Statistical alpha decay vs peers ($95\%$ confidence). |
| Peer Sharpe Healthy Threshold | $\text{Sharpe}_{\text{peer}} \ge 0.50 \implies$ Peer benchmark is healthy. |
| Rolling Evaluation Window | 60 trading days minimum. |
