# Standards for JSE Integration

| Metric | Engineering Standard |
|---|---|
| Ticker Format | JSE equity codes MUST be 3 uppercase letters (e.g. `NPN`). |
| Currency Convention | Order prices MUST be specified in **ZAC South African Cents** ($1\text{ ZAR} = 100\text{ ZAC}$). |
| Tick Size Rules | Order prices MUST conform to JSE Cent tick schedules ($5\text{ ZAC}$ for $P \ge 10,000\text{ ZAC}$). |
