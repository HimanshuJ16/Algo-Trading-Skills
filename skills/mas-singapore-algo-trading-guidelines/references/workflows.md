# Workflows for MAS Singapore Algo Compliance

1. **Governance & Sandbox Audit**:
   - Verify MAS registration ID, sandbox sign-off, and kill switch readiness.
2. **SGX Price Collar Audit**:
   - Verify order price is within $\pm 10\%$ of SGX reference price.
3. **Pre-Trade Value & Rate Limit Audit**:
   - Verify SGD order notional and order rate limits.
4. **Audit Report Generation**:
   - Output structured MAS compliance report.
