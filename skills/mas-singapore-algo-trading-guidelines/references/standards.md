# Standards for MAS Singapore Algo Compliance

| Metric | Engineering Standard |
|---|---|
| SGX Price Collar | Order prices MUST NOT deviate more than $\pm 10.0\%$ from SGX reference price. |
| MAS Algo Tagging | All SGX orders MUST specify a valid MAS registered algorithm ID. |
| Kill Switch Readiness | Automated kill switch capability MUST be active and ready. |
