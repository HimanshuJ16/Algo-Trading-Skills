# Standards for Constructive Sale Rule

| Metric | Engineering Standard |
|---|---|
| Section 1259 Applicability | Constructive sale rules MUST only apply to appreciated positions ($\text{FMV} > \text{Cost Basis}$). |
| Safe Harbor 30-Day Limit | The offsetting position MUST be closed on or before Jan 30 following tax year-end. |
| Safe Harbor 60-Day Unhedged | The underlying position MUST remain 100% unhedged for $\ge 60$ consecutive days post-close. |
