# Workflows for IaC Trading Host Management

1. **Host Spec Ingestion**:
   - Ingest proposed hardware, kernel, and network tuning spec.
2. **Low-Latency Benchmark Audit**:
   - Audit CPU governor, isolcpus, C-states, socket buffers, and PTP clock sync.
3. **Terraform & Ansible Code Generation**:
   - Generate automated HCL and playbook templates.
4. **Audit Report Generation**:
   - Output structured IaC compliance report.
