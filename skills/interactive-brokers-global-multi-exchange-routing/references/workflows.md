# Workflows for IBKR Global Routing

1. **Contract Definition & Validation**:
   - Verify symbol, security type, currency, and primary exchange.
2. **SmartRouting vs Direct Routing Selection**:
   - Assign `SMART` or explicit direct exchange destination.
3. **Regional Rules Verification**:
   - Audit US, European, and Asian market symbol formatting.
4. **Audit Report Generation**:
   - Output structured IBKR routing report.
