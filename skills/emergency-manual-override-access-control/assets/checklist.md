# Pre-Flight Checklist

- [ ] Are RBAC roles (`RISK_OFFICER`, `HEAD_TRADER`, `CTO`) configured for override permissions?
- [ ] Is dual sign-off enforced for critical firm-wide kill switch actions?
- [ ] Is a tamper-evident SHA-256 audit hash recorded for every override request?
- [ ] Is a 60-minute TTL auto-expiry configured for active overrides?
