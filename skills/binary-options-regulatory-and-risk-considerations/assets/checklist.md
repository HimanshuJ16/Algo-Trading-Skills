# Pre-Deployment Checklist

- [ ] Verify jurisdiction lists against latest CFTC/ESMA/FCA regulations.
- [ ] Confirm logic for `RETAIL` vs `PROFESSIONAL` client classification.
- [ ] Validate maximum notional limits are aligned with firm risk mandates.
- [ ] Ensure pin-risk calculations are correctly linked to the risk engine.
- [ ] Run full test suite for compliance edge cases (e.g., EU retail ban).
- [ ] Review system logs for rejected trades format and persistence.
- [ ] Legal sign-off on whitelisted venues.
