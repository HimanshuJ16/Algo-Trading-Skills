# Standards for Strategy Performance Attribution vs Market Beta

| Parameter | Standard Requirement |
|---|---|
| Statistical Significance | $|t_{\alpha}| \ge 1.96$ required for true alpha significance ($95\%$ confidence). |
| Factor Model Standard | Fama-French 3-Factor Model (MKT, SMB, HML) minimum for equity strategies. |
| $R^2$ Variance Standard | $R^2 \ge 0.75 \implies$ Returns dominated by systematic factors; low true alpha. |
