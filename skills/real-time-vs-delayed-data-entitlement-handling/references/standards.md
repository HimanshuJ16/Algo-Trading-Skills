# Standards for Real-Time vs Delayed Data Entitlement Handling

| Metric | Engineering Standard |
|---|---|
| Delayed Data Lag | Standard delayed data feed lag MUST be $\ge 15\text{ minutes}$. |
| Live Order Execution Policy | Live order execution MUST be strictly blocked on delayed data streams. |
| Subscriber Auditing | Subscriber classification (Pro vs Non-Pro) MUST be updated quarterly. |
