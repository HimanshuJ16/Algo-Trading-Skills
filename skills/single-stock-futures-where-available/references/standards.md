# Standards for Single Stock Futures Where Available

| Parameter | Standard Rule | Description |
|---|---|---|
| Cost of Carry Model | $F_{\text{fair}} = (S - \text{PV}(D)) e^{(r - q) T}$ | Theoretical fair value pricing model. |
| Ex-Dividend Base Price | $P_{\text{adj}} = P_{\text{prev}} - D$ | Ex-dividend price adjustment rule. |
| Arbitrage Threshold | $\pm 0.3\%$ mispricing | Triggers cash-and-carry or reverse cash-and-carry signals. |
