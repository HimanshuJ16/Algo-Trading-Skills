# Backtesting Methodology Standards — backtest-vs-live-performance-divergence-tracking

| Divergence Metric | Warning Threshold | Critical Threshold |
|---|---|---|
| Sharpe Decay | $>20\%$ | $>50\%$ |
| Drawdown Blow-Up | $>1.5\times$ backtest | $>2.0\times$ backtest |
| Fill Rate Gap | $>5\%$ | $>15\%$ |
| Slippage Amplification | $>2.0\times$ backtest | $>4.0\times$ backtest |
