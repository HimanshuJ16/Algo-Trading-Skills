# Pre-Flight Checklist

- [ ] Is observation window size ($T \ge 250$) sufficient for statistical validity?
- [ ] Is VaR exception count ($x$) accurately recorded against daily P&L?
- [ ] Is binomial test executed with two-sided alternative against expected rate $p = 1 - \alpha$?
- [ ] Is model rejection triggered if $p\text{-value} < 0.05$?
