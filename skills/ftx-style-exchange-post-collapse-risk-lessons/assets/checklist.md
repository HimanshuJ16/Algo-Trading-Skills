# Pre-Flight Checklist

- [ ] Is Proof of Reserves (PoR $\ge 100\%$) cryptographically audited?
- [ ] Is native exchange token collateral capped at $< 5\%$?
- [ ] Is Off-Exchange Settlement (OES) enabled for venue trading?
- [ ] Is single exchange NAV exposure capped at $\le 20\%$ with automated withdrawal triggers?
