# Workflows for Post-Collapse Exchange Risk Framework

1. **Exchange Solvency Audit**:
   - Audit Merkle-tree Proof of Reserves and Proof of Liabilities.
2. **Native Token Exposure Audit**:
   - Calculate native token collateral concentration percentage.
3. **Custodial OES Verification**:
   - Verify tri-party off-exchange settlement (ClearLoop, Fireblocks OES) status.
4. **De-Risking Execution**:
   - Execute automated capital withdrawal to cold custody upon risk threshold breach.
