# Standards for Options Chain Data Normalization Across Vendors

| Metric | Engineering Standard |
|---|---|
| Symbology Standard | OCC Option Symbology Initiative (OSI) 21-character format. |
| Strike Scaling | Strike price scaled $\times 1000$ zero-padded to 8 digits. |
| Ticker Padding | Ticker left-aligned space-padded to 6 characters. |
