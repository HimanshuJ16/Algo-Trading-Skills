# Pre-Flight Checklist

- [ ] Is metal code valid (`CA`, `AH`, `NI`, `ZS`, `PB`, `SN`)?
- [ ] Is lot size tonnage verified per metal ($25\text{ MT}$ for CA vs $6\text{ MT}$ for NI)?
- [ ] Is prompt date format verified (`'3M'`, `'CASH'`, or ISO YYYY-MM-DD)?
- [ ] Is USD/MT order price aligned with $\$0.50$/MT tick size?
