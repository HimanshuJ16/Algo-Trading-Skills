# Standards for LME Integration

| Metric | Engineering Standard |
|---|---|
| Contract Lot Sizing | Copper (`CA`), Aluminium (`AH`), Lead (`PB`), Zinc (`ZS`) MUST equal 25 MT; Nickel (`NI`) MUST equal 6 MT; Tin (`SN`) MUST equal 5 MT. |
| Price Tick Size | LMEselect order prices MUST conform to $\$0.50$/MT increments. |
| Benchmark Prompt | 3-Month (`'3M'`) is the primary rolling benchmark prompt. |
