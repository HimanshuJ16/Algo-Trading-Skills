# Pre-Flight Checklist

- [ ] Are multi-region DR failover workflows automated (no manual console clicks)?
- [ ] Is emergency cancel-all-orders signal verified before DNS traffic switchover?
- [ ] Is secondary database read-replica promotion automated?
- [ ] Are RTO ($\le 300\text{s}$) and RPO ($\le 15\text{s}$) SLAs tested in quarterly DR drills?
