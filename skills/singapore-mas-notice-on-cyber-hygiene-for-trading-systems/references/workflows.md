# Workflows for Singapore MAS Notice on Cyber Hygiene for Trading Systems

1. **Asset Identification**:
   - Inventory all trading system hosts (routers, gateways, execution engines, DBs).
2. **6-Control Audit**:
   - Evaluate MFA, admin restriction, 30-day patching, baseline hardening, network perimeter, and anti-malware.
3. **Remediation & Score Calculation**:
   - Calculate compliance score % and generate required remediation steps.
4. **MAS Regulatory Reporting**:
   - File audit report with IT risk committee and regulatory officer.
