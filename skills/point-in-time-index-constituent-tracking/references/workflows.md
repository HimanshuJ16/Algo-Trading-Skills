# Workflows for Point-in-Time Index Constituent Tracking

1. **Constituent Event Log Processing**:
   - Ingest chronological addition and deletion events per index.
2. **Point-in-Time Membership Query**:
   - Resolve active index membership for target trading date T.
3. **Survivorship Bias Audit**:
   - Audit delisted vs current constituents to measure survivorship bias impact.
4. **Audit Report Generation**:
   - Output structured PIT index report.
