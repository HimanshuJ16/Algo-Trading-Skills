# Workflows for FPGA Market Data Processing Evaluation

1. **Latency Profile Benchmarking**:
   - Ingest software CPU and FPGA SmartNIC latency distributions (p50, p99, max ns).
2. **Jitter & Tail Latency Calculation**:
   - Calculate latency reduction $\Delta L$ and tail jitter reduction ratio.
3. **Economic ROI Calculation**:
   - Calculate projected annual alpha gain vs hardware TCO.
4. **Architecture Selection**:
   - Recommend FPGA deployment or software CPU kernel-bypass optimization.
