# Standards for FPGA Market Data Processing Evaluation

| Metric | Engineering Standard |
|---|---|
| FPGA Target Latency | FPGA tick-to-trade latency MUST achieve $\le 300\text{ns}$ (p50). |
| Latency Savings Threshold | FPGA recommendation MUST require $\ge 1,000\text{ns}$ median latency reduction. |
| Economic Justification | Annual projected alpha gain MUST exceed total hardware/firmware TCO. |
