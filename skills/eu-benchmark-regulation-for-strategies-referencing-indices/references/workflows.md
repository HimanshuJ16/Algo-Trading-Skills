# Workflows for EU Benchmark Regulation (EU BMR)

1. **ESMA Register Audit**:
   - Verify administrator authorization on the ESMA Public Register.
2. **Article 28(2) Fallback Verification**:
   - Audit documented fallback benchmark and written plans.
3. **Cessation Preparedness**:
   - Test automated fallback rate substitution upon benchmark cessation events.
4. **Audit Report Emission**:
   - Issue compliance audit reports for European regulators.
