# Standards for Credit Default Swap Basics

| Metric | Engineering Standard |
|---|---|
| Recovery Rate Baseline | Senior unsecured CDS MUST default to $R = 40\%$ (0.40) recovery rate. |
| Standard Coupons | North American / European corporate CDS MUST use 100 bps (IG) or 500 bps (HY) coupons. |
| Day Count Convention | RPV01 and accrual calculations MUST use Actual/360 day count convention. |
