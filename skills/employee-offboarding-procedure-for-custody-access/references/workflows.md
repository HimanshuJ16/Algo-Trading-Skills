# Workflows for Employee Offboarding for Custody Access

1. **Access Revocation**:
   - Deactivate SSO, VPN, and custody portal accounts.
2. **API Key Destruction**:
   - Audit and delete all exchange API keys created by employee.
3. **Multi-Sig / MPC Key Rotation**:
   - Generate new private keys and re-key multi-sig wallet address.
4. **Hardware Token Wipe & Audit**:
   - Sanitize YubiKeys/Ledgers and issue SOC 2 audit report.
