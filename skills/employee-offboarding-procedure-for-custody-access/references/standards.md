# Standards for Employee Offboarding for Custody Access

| Metric | Engineering Standard |
|---|---|
| Key Rotation SLA | Multi-sig and MPC key rotation MUST complete within $\le 24\text{ hours}$ of termination. |
| API Key Purge | ALL exchange API keys associated with departing employee MUST be revoked instantly. |
| Audit Compliance | Offboarding audit logs MUST achieve $100\%$ task completion across all 5 verification steps. |
