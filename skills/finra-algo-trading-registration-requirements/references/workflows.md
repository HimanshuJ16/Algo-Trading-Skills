# Workflows for FINRA Algo Trading Registration

1. **Developer Registration Audit**:
   - Audit personnel roles against FINRA Rule 1220(b)(4) developer/supervisor criteria.
2. **License Verification**:
   - Query Series 57 and SIE active registration status.
3. **Change Scope Classification**:
   - Classify code commit as minor fix vs significant algorithm modification.
4. **Deployment Gate Enforcement**:
   - Approve compliant builds or block unregistered developer commits.
