# Standards for FINRA Algo Trading Registration

| Metric | Engineering Standard |
|---|---|
| FINRA Rule 1220(b)(4) Compliance | Algo developers/supervisors MUST hold active Series 57 & SIE registration. |
| Significant Modification Scope | Any logic change altering order generation/routing MUST trigger compliance audit. |
| Audit Trail Retention | Developer-to-algorithm commit mapping records MUST be retained for 6 years. |
