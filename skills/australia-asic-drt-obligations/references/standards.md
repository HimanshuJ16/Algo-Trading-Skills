# Standards for ASIC Derivative Transaction Rules (2024)

| Standard | ISO Format | Requirement |
|---|---|---|
| **LEI** | ISO 17442 | 20-character alphanumeric code identifying legal entities participating in financial transactions. |
| **UTI** | ISO 23897 | Up to 52-character alphanumeric code identifying the specific OTC transaction across its lifecycle. |
| **UPI** | ISO 4914 | 12-character code describing the OTC derivative product itself. |
| **Deadline** | N/A | Trades must be reported no later than T+2. |
