# Pre-Flight Checklist

- [ ] Are pre-trade price collar and max order size limits non-bypassable?
- [ ] Is the emergency Kill Switch operating outside the primary trading event loop?
- [ ] Is the algorithm registered in the institutional FinfraG inventory with an assigned governance owner?
- [ ] Are message rates throttled to $\le 100$ messages/second per FIX session?
- [ ] Is audit logging recording microsecond-precision UTC timestamps?
