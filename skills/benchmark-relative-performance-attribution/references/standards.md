# Institutional Standards — benchmark-relative-performance-attribution

| Metric | Target / Benchmark Standard | Description |
|---|---|---|
| Annualized Alpha ($\alpha$) | $> 0.0\%$ | Un-correlated excess return above CAPM beta |
| Beta ($\beta$) | Target-dependent ($0.80 - 1.20$) | Sensitivity to benchmark movement |
| Information Ratio ($IR$) | $\ge 0.50$ Good; $\ge 1.0$ Outstanding | Active return per unit of tracking error |
| Brinson Selection Effect | $> 0.0$ | Security selection skill within sectors |
