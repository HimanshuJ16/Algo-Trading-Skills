# Institutional Quant Standards for Blue-Green Deployments

## 1. Zero-Gap Data Continuity
- **Mandate:** Strategy instances MUST NOT drop a single packet of market data during cutover.
- **Implementation:** Both Blue and Green must process multicast A/B feeds concurrently prior to cutover. State sync handles the delta between Blue's processed state and Green's initialization.

## 2. Order Safety & idempotency
- **Mandate:** Cutover must not result in duplicate orders or dropped fills.
- **Implementation:** The execution gateway must enforce order ID idempotency. Any in-flight orders generated by Blue just prior to cutover must have their fills correctly routed back to Green's position manager.

## 3. Instantaneous Reversibility
- **Mandate:** If Green triggers a risk limit breach or generates malformed predictions, the system must revert to Blue in under 1 millisecond.
- **Implementation:** Blue remains actively updating its state from market data, merely ignoring its own signal generation output. Rollback is a simple pointer swap.

## 4. Hardware Resource Isolation
- **Mandate:** Green's initialization must not cause CPU cache thrashing or network congestion that impacts Blue's live trading performance.
- **Implementation:** Deploy Green to dedicated pinned CPU cores on the NUMA node separate from Blue, mapping only required shared memory.
