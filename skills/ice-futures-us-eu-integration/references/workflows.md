# Workflows for ICE Futures US & EU Integration

1. **Symbol & FIX Tag Formatting**:
   - Format ICE contract month symbol and FIX Tags 55, 207 (MIC), and 200.
2. **Valuation & Tick Alignment**:
   - Calculate notional value and verify price tick alignment.
3. **ICE Reasonability (NCR) Audit**:
   - Verify order price stays within exchange No-Cancellation Range limits.
4. **Order Execution Logging**:
   - Output structured ICE order report.
