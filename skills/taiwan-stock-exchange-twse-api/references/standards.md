# TWSE Regulatory & Technical Standards

- **Daily Price Limits**: Maximum $\pm 10\%$ fluctuation from the previous trading day's closing price.
- **Tick Size Table**:
  - $< \$50.00$: $\$0.01$
  - $\ge \$50.00$: $\$0.05$
- **Board Lot Size**: 1,000 shares for regular board lot trading. Intra-day odd lots (1-999 shares) routed on designated odd-lot book.
- **Short Selling**: Naked short selling strictly forbidden. Borrow locate required prior to placing short sell orders.
- **FINI ID Requirement**: All foreign institutional orders must be tagged with a registered FINI tax/custody ID.
