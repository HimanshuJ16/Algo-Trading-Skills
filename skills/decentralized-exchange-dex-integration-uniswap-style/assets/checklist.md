# Pre-Flight Checklist

- [ ] Are pool reserves ($x, y$) and swap fees ($\text{fee\_pct}$) parsed accurately?
- [ ] Is price impact calculated and audited before trade execution?
- [ ] Is minimum output amount ($\text{MinAmountOut}$) enforced with strict slippage limits?
- [ ] Are transaction deadlines ($t_{\text{deadline}}$) and MEV private RPC relays enabled?
