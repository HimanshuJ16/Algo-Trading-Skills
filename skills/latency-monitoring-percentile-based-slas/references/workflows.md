# Workflows for Latency Percentile SLA Monitoring

1. **Sample Ingestion & Sorting**:
   - Sort microsecond latency samples.
2. **Percentile & Jitter Calculation**:
   - Compute P50, P90, P95, P99, P99.9, and latency standard deviation.
3. **SLA Budget Audit**:
   - Compare percentiles against defined SLA thresholds.
4. **Audit Report Generation**:
   - Output structured SLA audit report.
