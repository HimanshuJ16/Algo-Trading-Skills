# Standards for Post-Trade Execution Quality Scorecard

| Metric | Engineering Standard |
|---|---|
| Implementation Shortfall Benchmark | Target IS MUST be $\le 10.0\text{ bps}$ for liquid US equities. |
| EQR Target | Effective-to-Quoted Ratio ($EQR$) SHOULD be $\le 1.0$ (at or inside spread). |
| Fill Rate Target | Order Fill Rate MUST exceed $95.0\%$ for full execution schedules. |
