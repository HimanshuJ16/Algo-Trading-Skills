# Standards for Exchange Tick Size Regime Tracking

| Metric | Engineering Standard |
|---|---|
| US Reg NMS Rule 612 | Stocks $\ge \$1.00$ MUST use $\$0.01$ ticks; stocks $<\$1.00$ use $\$0.0001$ ticks. |
| EU MiFID II RTS 11 | European equities MUST conform to price/liquidity band tick tables. |
| Off-Tick Rejection | Off-tick orders MUST be aligned prior to order submission. |
