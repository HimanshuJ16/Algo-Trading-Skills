# Pre-Flight Checklist

- [ ] Is physical asset quantity verified to match futures contract size?
- [ ] Is EFP basis ($P_{\text{futures}} - P_{\text{spot}}$) evaluated against theoretical carrying costs?
- [ ] Does the transaction satisfy CME Rule 538 / Eurex Rule 4.6 bona fide requirements?
- [ ] Is EFRP trade reporting payload generated for exchange clearing submission?
