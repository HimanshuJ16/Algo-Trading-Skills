# Standards for SEBI Algo Tagging

| Metric | Engineering Standard |
|---|---|
| Algo ID Requirement | EVERY automated order MUST carry a valid, exchange-approved Algo ID tag. |
| Client Category Tag | Orders MUST be explicitly tagged as `PRO` (Proprietary) or `CLI` (Client). |
| OTR Penalty Threshold | Daily OTR $\ge 2,000$ MUST trigger cooling-off alerts; $OTR \ge 500$ triggers warning. |
