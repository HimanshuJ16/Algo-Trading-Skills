# Workflows for SEBI Algo Tagging Compliance

1. **Algo ID Registration Audit**:
   - Verify unique Algo ID is registered with exchange and category (PRO/CLI) is specified.
2. **OPS Rate Threshold Verification**:
   - Audit orders per second against 10 OPS threshold limit.
3. **Daily OTR Surveillance Monitoring**:
   - Compute Order-to-Trade Ratio and alert on OTR penalty levels.
4. **Audit Report Generation**:
   - Output structured SEBI compliance report.
