# Standards Reference — stress-testing-against-historical-crash-scenarios

| Parameter | Value | Description |
|---|---|---|
| Max Stressed Loss Threshold | 15% of NAV | Hard gate to block new entries |
| Built-in Scenarios | 2008 GFC, 2015 Flash Crash, 2020 COVID | Default scenario library |
| Default Fallback Return | -30% | Applied to assets not in scenario definition |

## Category

`risk-management`

## Regulatory Notes

Aligns with Basel III stress-testing frameworks, SEC Rule 15c3-5, and ESMA guidelines on algorithmic trading risk controls.
