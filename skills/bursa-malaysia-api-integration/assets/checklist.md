# Pre-Flight Checklist

- [ ] Has the BTS2-A1 form been formally signed off by the exchange?
- [ ] Is the `TargetCompID` correctly configured for the desired order book (`FIXTRADER` vs `FIXNEGDEAL`)?
- [ ] Has the FIX engine been configured for version 5.0 SP1?
- [ ] Have all mandatory certification test cases been executed and logged?
