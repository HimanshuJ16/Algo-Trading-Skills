# Standards for Bursa Malaysia Integration

| Standard | Description |
|---|---|
| Protocol | FIX 5.0 SP1 |
| Connection Protocol | TCP over Site-to-Site VPN or BCS Cross-Connect |
| TargetCompID (Lit) | `FIXTRADER` |
| TargetCompID (Dark/Direct) | `FIXNEGDEAL` |
| Heartbeat | 30 seconds standard |
