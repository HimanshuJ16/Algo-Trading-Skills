# Workflows for Order Book Microstructure Signal Research

1. **Microstructure Feature Extraction**:
   - Compute Order Flow Imbalance (OFI), Volume Imbalance (VOI), and Micro-Price.
2. **Forward Return & IC Calculation**:
   - Compute forward return R_{t+k} and calculate Information Coefficient (IC = Corr(Feature, Return)).
3. **Efficacy Audit**:
   - Evaluate hit ratio and t-statistic for feature predictive power.
4. **Audit Report Generation**:
   - Output structured microstructure signal report.
