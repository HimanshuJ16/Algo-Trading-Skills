# Standards for Order Book Microstructure Signal Research

| Metric | Engineering Standard |
|---|---|
| Minimum Information Coefficient (IC) | $|IC| \ge 0.05$ for forward predictive alpha. |
| Hit Ratio | Minimum $\ge 53\%$ directionally correct predictions. |
| Micro-Price Formula | $P_{\text{micro}} = \frac{V_{\text{bid}} P_{\text{ask}} + V_{\text{ask}} P_{\text{bid}}}{V_{\text{bid}} + V_{\text{ask}}}$. |
