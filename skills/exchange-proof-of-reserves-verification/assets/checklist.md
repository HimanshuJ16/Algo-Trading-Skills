# Pre-Flight Checklist

- [ ] Is user account balance included in the declared Merkle Sum Tree snapshot?
- [ ] Are Merkle audit path SHA-256 hashes verified up to the declared Merkle Root?
- [ ] Are negative balances ($u_i < 0$) audited and prohibited in Merkle nodes?
- [ ] Is the exchange on-chain reserve ratio verified to be $\ge 100.0\%$?
