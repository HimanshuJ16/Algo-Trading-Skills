# Workflows for Post-Mortem Culture and Blameless Review Process

1. **Language Scan & Blame Detection**:
   - Audit post-mortem text for accusatory terminology.
2. **Systemic Reframing**:
   - Reframe human mistakes into systemic process and tool gaps.
3. **Report Generation**:
   - Generate blameless post-mortem markdown document.
4. **Audit Report Output**:
   - Output structured blameless post-mortem report.
