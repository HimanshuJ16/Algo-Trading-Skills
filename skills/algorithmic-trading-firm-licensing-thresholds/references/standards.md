# Standards for Licensing Thresholds

| Jurisdiction | Rule | Trigger for Mandatory Licensing |
|---|---|---|
| **US** | SEC Rule 15b9-1 | Any proprietary off-exchange trading requires FINRA membership. |
| **EU** | MiFID II | High message rates trigger HFT designation, requiring Investment Firm licensing. |
| **IN** | SEBI Algo Rules | Exceeding standard retail Orders Per Second limits requires formal Algo Registration. |
| **Global** | Customer Funds | Handling or trading customer funds universally triggers broker/advisor licensing. |
