# Standards for Risk-Adjusted Performance Attribution Per Strategy

| Metric | Engineering Standard |
|---|---|
| Sharpe Ratio | Annualized: $\frac{R_{ann} - R_f}{\sigma_{ann}}$, using 252 trading days. |
| Sortino Ratio | Uses downside deviation only (negative excess returns). |
| Max Drawdown | Peak-to-trough decline in cumulative equity curve. |
| Calmar Ratio | $\frac{R_{ann}}{MaxDD}$. |
