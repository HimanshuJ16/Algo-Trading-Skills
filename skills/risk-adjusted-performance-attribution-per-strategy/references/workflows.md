# Workflows for Risk-Adjusted Performance Attribution Per Strategy

1. **Per-Strategy Metric Calculation**:
   - Compute annualized return, vol, Sharpe, Sortino, max drawdown, Calmar per strategy.
2. **Portfolio-Level Blended Returns**:
   - Construct weighted aggregate portfolio daily returns.
3. **Marginal Risk Contribution**:
   - Decompose each strategy's weighted volatility as % of total portfolio risk.
4. **Attribution Report Generation**:
   - Output structured portfolio attribution report with ranked strategies.
