# Workflows for Regulatory Custody Requirements by Jurisdiction

1. **Jurisdiction Rule Retrieval**:
   - Map target jurisdiction to mandatory custody requirements.
2. **Custodian Classification Check**:
   - Verify custodian meets qualified status where required.
3. **Segregation & Audit Check**:
   - Verify client asset segregation, annual audit, and insurance coverage.
4. **Audit Report Output**:
   - Output structured custody compliance report with flagged violations.
