# Workflows for Deribit Crypto Options API

1. **JSON-RPC 2.0 Request Setup**:
   - Build JSON-RPC 2.0 payloads for Deribit API v2 endpoints.
2. **Inverse Premium Conversion**:
   - Convert coin-denominated premiums and margins into USD metrics.
3. **Portfolio Greeks Calculation**:
   - Aggregate Delta, Gamma, Vega, and Implied Volatility (IV).
4. **Order Execution**:
   - Check available margin and dispatch order.
