# Standards for Execution Algo Regression Testing Suite

| Metric | Engineering Standard |
|---|---|
| MiFID II RTS 6 Compliance | Code releases MUST pass automated regression testing prior to live deployment. |
| Max Shortfall Degradation | Candidate IS MUST NOT degrade by $> +2.0\text{ bps}$ over baseline. |
| Min Fill Rate Ratio | Candidate fill rate MUST achieve $\ge 98.0\%$ of baseline fill rate. |
