# Workflows for Prime Brokerage Multi-Venue Consolidation

1. **Trade Execution Ingestion**:
   - Aggregate execution fills across all executing brokers and venues.
2. **Netting & Margin Consolidation**:
   - Net positions per symbol and compute consolidated margin requirements.
3. **Give-Up Payload Generation**:
   - Generate standardized give-up clearing payload for Prime Broker.
4. **Audit Report Generation**:
   - Output structured PB consolidation report.
