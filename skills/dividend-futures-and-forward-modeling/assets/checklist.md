# Pre-Flight Checklist

- [ ] Are discrete dividend events ($D_i, t_i$) verified prior to contract expiration $T$?
- [ ] Is discrete dividend present value ($\text{PV}(D)$) calculated using continuous discounting ($e^{-r t_i}$)?
- [ ] Are theoretical forward price $F(0, T)$ and fair value dividend futures computed?
- [ ] Are cash-and-carry arbitrage opportunities flagged against transaction cost thresholds?
