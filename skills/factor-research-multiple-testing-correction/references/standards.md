# Standards for Factor Research Multiple Testing Correction

| Metric | Engineering Standard |
|---|---|
| Harvey-Liu-Zhu Hurdle | New factor discoveries MUST achieve $t \ge 3.0$ ($p \le 0.0027$). |
| False Discovery Rate (FDR) Target | FDR target $q^*$ MUST NOT exceed $0.05$ (5% max false positives). |
| Multiple Testing Audit Mandatory | All factor screening batches ($M \ge 10$) MUST undergo BH FDR correction. |
