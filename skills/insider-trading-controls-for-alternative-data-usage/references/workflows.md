# Workflows for Alt Data Insider Trading Compliance

1. **MNPI & Legal Due Diligence Audit**:
   - Audit dataset for Material Non-Public Information risks and vendor diligence signoff.
2. **PII Anonymization Audit**:
   - Audit PII scrubbing and verify panel aggregation size ($\ge 50$ observations).
3. **Earnings Blackout Window Check**:
   - Verify dataset trading is paused during $\pm 48\text{h}$ earnings release windows.
4. **Audit Report Generation**:
   - Output structured alt-data compliance report.
