# Standards for Alt Data Insider Trading Controls

| Metric | Engineering Standard |
|---|---|
| MNPI Policy | Datasets containing Material Non-Public Information MUST NOT be used for trading. |
| Vendor Due Diligence | Written vendor compliance representation MUST be on file. |
| PII Panel Aggregation | Consumer data MUST be aggregated across $\ge 50$ distinct panel observations. |
| Blackout Window | Datasets MUST enforce a $\pm 48\text{h}$ blackout window around earnings releases. |
