# Pre-Flight Checklist

- [ ] Is 10-digit National Investor Number (NIN) populated in FIX Tag 1 (`Account`)?
- [ ] Is order currency set to AED (United Arab Emirates Dirham)?
- [ ] Are AED tick size rules (0.001, 0.01, 0.02, 0.05 AED) validated prior to submission?
- [ ] Is 10% daily price band circuit breaker verified against prior settlement?
