# Workflows for Model Card Generation

1. **Model Identity & Governance Ingestion**:
   - Collect model metadata, author info, and MRM validation sign-off.
2. **Performance Metrics Verification**:
   - Ingest backtest performance metrics and capacity bounds.
3. **Markdown & JSON Generation**:
   - Synthesize standardized Model Card markdown report and JSON schema.
4. **Audit Report Generation**:
   - Output structured Model Card report.
