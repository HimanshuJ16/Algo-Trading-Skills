# Standards for Options Flow Unusual Activity Detection

| Metric | Engineering Standard |
|---|---|
| Minimum V/OI Ratio | $V/OI \ge 1.5$ (Volume exceeds 150% of open interest). |
| Minimum Premium USD | Minimum $\ge \$100,000$ USD total premium value. |
| Aggressor Direction | Execution $\ge$ Ask $\implies$ Buy; Execution $\le$ Bid $\implies$ Sell. |
