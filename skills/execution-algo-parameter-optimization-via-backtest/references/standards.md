# Standards for Execution Algo Parameter Optimization

| Metric | Engineering Standard |
|---|---|
| Objective Metric | Optimization MUST minimize Expected IS + Volatility Penalty + Incomplete Fill Penalty. |
| In-Sample / Out-of-Sample Split | Parameter tuning MUST be validated on out-of-sample test datasets. |
| Participation Ceiling Guard | Participation rate $\alpha_{\text{max}}$ MUST NOT exceed $25\%$ of market ADV. |
