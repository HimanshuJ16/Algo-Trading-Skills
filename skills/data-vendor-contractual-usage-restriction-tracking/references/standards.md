# Standards for Data Vendor Contractual Usage Restriction Tracking

| Metric | Engineering Standard |
|---|---|
| Non-Display License Enforcement | Automated trading bots MUST be verified for non-display licensing prior to API connection. |
| External Redistribution Lock | External client quote redistribution MUST be hard-blocked unless a redistribution license is active. |
| Concurrency Headroom | Active concurrent system entitlements MUST NOT exceed contract seat limits. |
