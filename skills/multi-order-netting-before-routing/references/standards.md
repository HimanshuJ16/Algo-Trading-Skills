# Standards for Multi-Order Netting Before Routing

| Metric | Engineering Standard |
|---|---|
| Internal Match Price | Internal crossing MUST occur at mid-price $P_{\text{mid}} = (P_{\text{bid}} + P_{\text{ask}}) / 2$. |
| Net Residual Formula | $Q_{\text{residual}} = |Q_{\text{buy}} - Q_{\text{sell}}|$. |
| Cost Savings Calculation | $\text{Fee Savings} = 2 \cdot Q_{\text{matched}} \cdot \text{Fee}, \text{Spread Savings} = Q_{\text{matched}} \cdot \text{Spread}$. |
