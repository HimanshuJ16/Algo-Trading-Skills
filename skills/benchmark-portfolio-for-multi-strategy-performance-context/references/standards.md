# Benchmarking Standards

| Metric | Rule |
|--------|------------|
| Information Ratio | Good: $> 0.5$, Excellent: $> 1.0$. Negative values indicate destruction of value relative to the benchmark. |
| Beta | For market-neutral portfolios, Beta to the equity market must be between $-0.1$ and $+0.1$. |
| Tracking Error | Must be annualized using $\sqrt{252}$ for daily return series. |
