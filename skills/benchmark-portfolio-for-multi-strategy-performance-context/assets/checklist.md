# Pre-Flight Checklist

- [ ] Are the portfolio and benchmark return series exactly the same length and aligned by date?
- [ ] Is the chosen benchmark appropriate for the multi-strategy fund's mandate (e.g., Absolute Return vs Relative Return)?
- [ ] Have you verified the risk-free rate represents the correct period (e.g., properly adjusted to daily)?
- [ ] Are the calculated Beta and Alpha values statistically significant over a multi-year horizon?
